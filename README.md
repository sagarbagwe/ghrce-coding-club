# GHRCE Coding Club

A small, polished, frontend-only coding club website for **G H Raisoni College of Engineering, Nagpur**.

> This is a demonstration website. Event details, project listings, statistics, member names, email, and social profiles are sample placeholders unless explicitly linked to the official college website.

## Tech stack

- React + Vite
- JavaScript
- Tailwind CSS
- Lucide React

## Run locally

```bash
npm install
npm run dev
```

## Production checks

```bash
npm run lint
npm run build
npm run preview
```
